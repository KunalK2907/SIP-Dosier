# SIP Dossier – Kunal Kishore

A four-section digital internship portfolio created for the Internship Canvas / placement preparation activity.

## Structure
1. Company & Industry Overview
2. Internship Experience & Objectives
3. Tasks Completed & Key Learnings
4. Conclusion

## How to publish on GitHub Pages
After uploading these files to a GitHub repository:
1. Open **Settings**
2. Open **Pages**
3. Under **Build and deployment**, choose **Deploy from a branch**
4. Select the `main` branch and `/ (root)`
5. Save

The site will then be available through GitHub Pages.
